# CTF Writeups

Dokumentasi penyelesaian CTF/lab hacking. Setiap writeup punya folder sendiri dengan format konsisten: challenge description, recon, exploitation, dan flag.

## 📋 Template

Lihat [`example-writeup/`](./example-writeup) untuk format yang dipakai tiap writeup baru.

## 📝 Daftar Writeup

| Platform | Challenge/Room | Kategori | Status |
|---|---|---|---|
| Self-hosted | [Mini CTF: Login Bypass](./mini-ctf-web-auth-bypass) | Web (SQLi) | ✅ Selesai |
| Contoh | Example Writeup | Web | ✅ Template |
| _(isi setelah selesai CTF di platform beneran, misal TryHackMe)_ | | | |

## 🎯 Cara Nambah Writeup Baru

1. Copy folder `example-writeup/` jadi folder baru dengan nama challenge
2. Isi `README.md` mengikuti format template
3. Update tabel di atas
